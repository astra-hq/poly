--- Ledger Table ---
knowledge_graph_ingestion_chunks:
  meeting_id TEXT, profile_id TEXT, chunk_sequence INTEGER, chunk_fingerprint TEXT,
  file_source TEXT, status TEXT, track_id TEXT, last_error TEXT,
  created_at TEXT, updated_at TEXT
  UNIQUE(meeting_id, profile_id, chunk_sequence, chunk_fingerprint)

--- Ingest Flow ---
1. Validate profile_id (reject "none"/empty)
2. Load transcripts via sqlx::query_as::<Transcript>
3. Map to TranscriptRow, chunk with TranscriptChunker(20s)
4. For each chunk: SHA256 fingerprint → file_source → ledger check
5. Skip if status='submitted'/'completed' → already_submitted
6. Retry if 'pending'/'failed' → call provider.insert_text()
7. On success → status='submitted', track_id set
8. On failure → status='failed', last_error set
9. Return IngestionSummary with per-chunk breakdown
